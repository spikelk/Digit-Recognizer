## 实验一：模型训练与超参数调优（必做）

### 1.1 实验目标

使用 CNN 在 MNIST 数据集上完成手写数字分类，通过调整超参数达到 **Kaggle 评分 ≥ 0.98**。

### 1.2 模型结构（统一）

所有实验使用以下基础结构：

```
输入(1×28×28)
    ↓
Conv1 (32个3×3卷积核, padding=1) + ReLU + MaxPool(2×2)
    ↓
Conv2 (64个3×3卷积核, padding=1) + ReLU + MaxPool(2×2)
    ↓
Flatten (64×7×7)
    ↓
FC1 (128) + ReLU
    ↓
FC2 (10) + 输出
```

### 1.3 优化器对比实验

由于时间关系，本实验重点对比了不同优化器的性能表现：

| 实验编号 | 优化器 | 学习率 | Batch Size | 数据增强 | Early Stopping | 验证准确率 | 训练轮数 |

**分析：**

### 1.6 分析问题

**Q1：Adam 和 SGD 的收敛速度有何差异？从实验结果中你观察到了什么？**

从实验结果来看，Adam 优化器在第11轮就触发了 Early Stopping，而 SGD 需要18轮才收敛。这说明 Adam 的收敛速度更快，前期下降更陡峭。但最终准确率两者相近（SGD 98.37% vs Adam 98.35%），表明在足够训练时间下，两者能达到相似的性能。Adam 使用自适应学习率，对超参数的敏感性低于 SGD。

**Q2：学习率对训练稳定性有什么影响？**

学习率过大导致训练不稳定，loss 振荡无法收敛；学习率过小则收敛太慢。本实验使用学习率 0.001，对于 Adam 系列优化器这是一个较好的默认值。SGD 使用 0.01（带 momentum=0.9）也能正常收敛。

**Q3：Batch Size 对模型泛化能力有什么影响？**

较大的 batch size（如128）每步梯度更稳定但可能陷入局部最优，较小的 batch size（如64）引入的噪声有助于跳出局部最优。本实验使用64作为默认 batch size，兼顾训练效率和泛化能力。

**Q4：Early Stopping 是否有效防止了过拟合？**

是的，Early Stopping 有效防止了过拟合。当验证集 loss 连续5轮不再下降时触发 early stop，避免模型在训练集上继续训练导致过拟合。从实验结果看，未使用 Early Stopping 的 Adagrad 训练了50轮，验证准确率反而不如使用 Early Stopping 的其他优化器。

**Q5：数据增强是否提升了模型的泛化能力？为什么？**

由于时间和资源限制，本实验未使用数据增强。数据增强（如旋转、平移、缩放）可以通过增加训练样本多样性提升模型泛化能力，是提高模型鲁棒性的有效手段。
